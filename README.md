# AI-Assisted Cavities under restoration Detection Framework

##📌 Overview

This repository presents an AI-assisted framework for detecting caries under restorations and orthodontic braces (CuRB) in dental bitewing radiographs.
The proposed system integrates image preprocessing, structural segmentation, region-of-interest (ROI) localization, and deep learning-based classification to support clinical diagnosis.

Detecting CuRB is clinically challenging due to radiographic artifacts introduced by high-density materials such as restorations and orthodontic appliances. This framework aims to enhance diagnostic consistency and reduce visual ambiguity through a structured and automated analysis pipeline.
----------------------------------------------------------------------------------------------------------------------------------------------------------------------
##📌 Feature
- Bitewing radiograph preprocessing
- Tooth segmentation and half-tooth representation
- ROI localization for CuRB analysis
- Image enhancement for lesion visibility
- Deep learning-based CuRB classification
- Output visualization for clinical interpretation
